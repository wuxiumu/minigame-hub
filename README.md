# 🎮 minigame-hub

收集汇总各类小游戏，记录评测与拆解，并孵化自研小游戏。

## 目录结构

```
games/     收录的小游戏档案（每个游戏一篇评测）
reviews/   评分体系与评测模板
dev/       自研小游戏开发区
docs/      方法论与笔记
```

## 快速导航

- 📋 [评分体系](reviews/rubric.md)
- 📝 [游戏档案模板](games/_template.md)
- 🎯 [自研游戏](dev/)

## 工作流程

1. **发现**：在 `games/` 下为每个游戏建一篇档案
2. **评测**：用 `reviews/rubric.md` 的维度打分
3. **拆解**：值得学习的游戏，深挖其设计亮点
4. **自研**：灵感落地到 `dev/`，做出可玩的原型
